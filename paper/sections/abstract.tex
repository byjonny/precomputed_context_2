Abstract. Repeating a model's input has recently emerged as a simple way to improve its behavior. One line of work shows that re-encoding a query produces better text embeddings: under causal attention, only the last token sees the whole input, but when the query is repeated, even the first repeated token already sees the entire original input to its left, so its representation improves, and this gain propagates rightward through the second copy. A closely related result shows that this same repetition raises task accuracy for non-reasoning language models, while accuracy for reasoning models stays neutral, since they already restate the prompt within their own reasoning. So far, however, this idea has only been applied to repeating the raw problem.
A separate line of work studies the reuse of reasoning traces. Instead of repeating the query, these methods convert prior chain-of-thought into compact, reusable insights and supply them alongside a new problem. This guides reasoning models toward an effective solution path and reduces wasted exploration, while non-reasoning models gain in downstream task accuracy. This raises a natural question that neither line addresses: if repeating the problem helps, and supplying a reasoning insight helps, does repeating the insight rather than only the problem help non-reasoning models even further?
We call this Think Twice. We treat a problem and a precomputed insight as composable prompt blocks and systematically vary how often each is repeated and in which order they appear, reusing released skill-card text as the insight so that no separate extraction or retrieval pipeline is required. We report preliminary results on a non-reasoning model and discuss which factor, content, repetition, or ordering, drives the effect. (Results placeholder, to be finalized.)
